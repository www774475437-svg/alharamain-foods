# Al-Haramain International Foods — الحرمين للأغذية العالمية

تطبيق ويب للتسوق (يعمل كموقع ويمكن تثبيته كتطبيق) لفروع الحرمين الأربعة في ميشيغان.

| الملف | وظيفته |
|---|---|
| `branches.js` | الفروع (العنوان، الهاتف، اللون، البانر) + عروض كل فرع ومنتجاته الخاصة + أسماء الأقسام |
| `catalog.json` | المنتجات: الاسم، السعر، السعر القديم، التوفر، الصورة، القسم |
| `app.js` / `style.css` / `index.html` | الواجهة |

## عروض خاصة بفرع
في `branches.js` داخل الفرع:
```js
deals: [ { match: "Medjool", price: 19.99 } ]
```
